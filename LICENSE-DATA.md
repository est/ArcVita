## Why dual-license

- Upstream facts come from **Wikidata** (CC0) and **Wikipedia** (CC BY-SA 4.0). CC0 facts can be relicensed freely; any substantial excerpt or adapted prose from Wikipedia remains CC BY-SA 4.0.
- Our **curated narratives** (`summary_first_person`, `Endeavor.description_zh`, `lesson`) are original writing. We publish them under CC BY-SA 4.0 so that downstream use stays share-alike and compatible with the Wikipedia-derived portions.
- Pure **code** under MIT keeps integration permissive (commercial use allowed, no copyleft on code).

## Attribution

When you reuse the data, attribute:

> Data from ArcVita (https://github.com/<org>/ArcVita), derived in part from Wikidata (CC0) and Wikipedia (CC BY-SA 4.0), curated additions CC BY-SA 4.0.

If you only reuse the code, MIT attribution suffices.

## Not CC BY-SA

CC BY-SA is **not recommended for code** (it is copyleft and a poor fit for software). That's why code stays MIT. If you need a single license for everything, CC BY-SA covers the data; MIT covers the code — pick the one that matches what you're reusing.
