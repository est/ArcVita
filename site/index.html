WHY · 出发点

人物传记只能一本一本读，同时期一多，就理不清。

时间跨度一长就得来回翻，同期人物一多关系就成了一团乱麻。所以做一条轴： 以「做事」为主线，让人生变成可以横着走、可以聚焦、可以对比的东西。

  1. 01

    记完整周期 已就绪

    把值得记住的人——模范或教训——按「做事」记录完整周期：怎么缘起，经历什么阶段，在什么地方，做了什么决定。

  2. 02

    穿插名场面 已就绪

    成语诞生的那一刻、代表作公布的那一天、关键决策的转折点——让历史有画面感。轴上的朱砂色圆点就是它们。

  3. 03

    天下共主世系 已就绪

    公元纪年普及之前，当时的人说日期得有参考系——所以君主世系必须不间断，每个人物至少能对上一个当时的「天下共主」。

  4. 04

    同龄对比 后期

    不同朝代的人在同一「年龄」在做什么？同一时代发生了什么大事？横向对比人生刻度。

  5. 05

    境遇检索 后期

    人生迷茫的时候，找到类似境遇的历史人物，看他的做事周期，得到启发。

HOW · 设计理念

做事流，不是流水账。

传统传记按时间罗列事件，是上帝视角的第三人称观察。但主角是第一人称在做事—— 当时的他不知道未来，也受时代与身边人的限制。所以每件事都拆成四个阶段来看。

拆阶段，看见起伏 酝酿 · 破局 · 高潮 · 收束

聚焦一个人物，TA 的每件事展开为四色阶段条：灰蓝的酝酿、鎏金的破局、朱砂的高潮、玉绿的收束。 起伏一眼可见，而不是一串等权重的年份。

同期年龄对比 同一时刻，各自几岁

悬停任何一个事件点，一根金色时间线落下，所有存活人物的名字旁亮出他们当时的年龄； 死了的不显示，本人用棕色高亮，鼠标移开自动清除。 「公元前 356 年商鞅变法时，大家分别几岁」——一眼就知道。

去时间轴上试一试 ↑

天下共主世系 时间轴不许间断

轴的底部是不间断的世系条。在纪年没能普及的古代，君主的世系就是当时的「日历」—— 每个人物、每件事，都能挂回到某个天下共主的年头上。

SPEC · 交互规格

四种玩法，一条对角线。

人物按出生年从上往下排：最古老在左上，最新在右下。 沿对角线拖拽，时间就流过你的手指。

  • 基础漫游

    水平滚动浏览全部历史，1× = 10px/年，1920px 宽的屏幕约看 200 年。 每个人从出生到死亡是一根朝代色横条，人生大事是条上的圆点。拖拽带惯性，滚轮以光标为锚缩放。

    已上线

  • 聚焦模式

    点击人物行 → 自动缩放到 TA 的人生范围（±15% 缓冲）， 展开事业周期条、四色阶段标注与事件详情；ESC 或再次点击 → 返回全局概览。

    已上线

  • 同期年龄

    悬停事件点，同时代所有存活人物的名字旁显示当时年龄；本人棕色高亮， 已故的不显示，鼠标移走自动清除。

    已上线

  • 非欧几里得滚动

    仿 Poincaré 盘的时间压缩：不做常规 Web 滚动，而是斜向拖拽。 人物众多处局部纵横滚动；人少处持续一拖，就看到时间流逝、人物此消彼长。

    规划中

RUN · 快速开始

一分钟，本地跑起来。

点击任意一行即可复制。

$uv sync复制
$uv run python -m arcvita.cli # 全量采集复制
$uv run python scripts/build_site.py # 构建前端数据复制
$uv run python -m http.server -d site 8080 # 本地预览复制
$
