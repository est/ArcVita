# ArcVita — 成事儿时间轴

> 历史上的伟大人物，浩若烟海。如何在一个统一的框架里去从TA们的人生阅历中，得到启发？
> 你是否也好奇过，李世民18岁在干嘛？
> 爱因斯坦最早从什么时候开始对前沿物理问题着迷并进行投入的？到做出成果经历了哪些人生阶段？

## 出发点

这个项目的初衷很简单：人物传记只能一个一个读，同时期人物一多理清关系就困难，时间跨度长就需要来回翻。

我们想做的是：

1. 把历史上值得记住的人（模范或教训），按照"做事"为主线，记录完整周期——一件事从开头到结束，怎么缘起，经历了什么阶段，在什么地方，做了什么决定。
2. 穿插名场面——成语诞生的那一刻、代表作公布的那一天、关键决策的转折点——让历史有"画面感"。
3. 普通人就代表作、思想，或者成就了某事。但是一个时代、地区的多人呢？可能需要一个「天下共主」作为坐标。所以在「公元纪年」没能普及的古代，君主的世系必须不能间断，当时的人说日期才能有参考系。
4. 【后期】按时间轴横向对比：不同朝代的人在同一"年龄"在做什么？同一时代发生了什么大事？
5. 【后期】用户在觉得人生特定阶段的时候，比如迷茫，可以找到类似境遇的历史人物，看他的做事周期，得到启发。


## 设计理念

### 做事流，不是流水账
传统传记按时间罗列事件，像上帝视角第三人称去观察，但主角第一人称做事，在当时是不知道未来的，也受到时代限制和周围的人的影响。

### 同期年龄对比
hover 任何一个事件点，所有存活人物的名字旁会显示他们当时的年龄。一眼就能看到"公元前 356 年商鞅变法时，大家分别几岁"

### 天下共主世系
尽可能保证时间轴不间断。每个历史人物至少能对应上一个当时的「天下共主」


## 时间轴交互

### 基础
- 水平滚动浏览全部历史（左上 = 最古老，右下 = 最新）
- 1x = 10px/年，假设1920px 屏幕差不多能看 200 年左右
- 每个人从出生到死亡，所有人生里的重大事件展示为一个点，点击可以在popover里查看

### 聚焦模式
- 点击人物行 → 自动缩放到该人物的人生范围（±15%缓冲）
- 聚焦时展开事业周期条 + 阶段标注 + 事件详细
- 再次点击 / ESC → 返回全局概览

### 同期年龄
- hover 事件点时，同时代所有存活人物的名字旁显示年龄
- 本人用棕色高亮，死了的不显示
- 鼠标移走自动清除

### 高级交互：非欧几里得滚动

从上往下，人物按出生年龄排列。这样浏览的大概顺序是从左上一直拉到右下。

这种基础设定决定了，如果你不小心滚动到 右上角，那么是没有人存在的。左下角同理。考虑仿造 Poincaré 盘那种设计，不做常规的Web滚动，改为非欧几里得拖拽。

鼠标滚轮或者 touchpad 滚动，时间轴以斜向方式滚动。如果同一时期人物众多，也可以局部垂直滚动+水平滚动；

如果人少，持续滚动就可以看到时间流逝，人物此消彼长。

## 项目结构

```
ArcVita/
├── src/           # Python 采集流水线，构建脚本
├── site/                  # 前端源码
├── data/                  # 数据源
├── tests/                 # 校验测试
└── .github/workflows/     # GitHub Actions 自动部署
```

## 快速开始

```bash
uv sync
uv run python -m arcvita.cli          # 全量采集
uv run python scripts/build_site.py   # 构建前端数据
uv run python -m http.server -d site 8080  # 本地预览
uv run pytest tests/ -v              # 准入校验
```

## 技术栈

- **采集**：Python + httpx + pydantic + PyYAML + SQLite
- **AI 提取**：MiMoCode subagent 批量处理古籍文言文
- **前端**：纯 HTML/CSS/JS，无框架，Poincaré 时间压缩，自适应刻度
- **部署**：GitHub Actions → GitHub Pages
- **许可证**：代码 MIT，数据 CC BY-SA 4.0
